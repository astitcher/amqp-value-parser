An experimental, work-in-progress C library and small toolset for parsing AMQP 1.0 "value" syntax into Apache Qpid Proton pn_data objects and for encoding/inspecting AMQP frames. Intended for testing, debugging, and embedding a simple AMQP value parser into projects that use Proton.

This project is experimental — APIs, generated files, and on-disk artifacts may change while development continues.
